# Architecture Decision Records

`NNN-short-slug.md`, immutable once accepted (supersede with a new ADR instead of editing).

```markdown
# ADR NNN: Title

Status: accepted | superseded by ADR-MMM
Date: YYYY-MM-DD

## Context
The question and the forces at play.

## Options considered
Brief, honest pros/cons. If an agent panel debated this, summarize each agent's position.

## Decision
What we chose and why.

## Consequences
What this commits us to; what it makes harder.
```
